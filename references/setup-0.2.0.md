# Setup 0.2.0

Run `python3 configure.py` to launch the five-page field-notebook wizard. Settings use the same XDG path as the native MCP worker. Saving never inventories the archive. Scripted flags remain available, including a --roots alias and explicit capability disable flags.

Valid policy changes reload before the next worker request and clear captured evidence. Malformed settings block collection. Optional private status sockets compare policy revisions in observed workers; unsupported sockets or old workers are explicitly unobserved. Fresh subprocess verification remains a separate result.

The wizard can invoke the native `agy plugin install` command after saving. Installation requires the user's local Antigravity CLI and remains owned by its installer. Upgrading a pre-0.2 running worker requires one reconnect.

The isolated runtime installs dependencies only during interactive setup when needed. MCP startup performs no dependency downloads. No scheduler or ongoing usage collector is introduced.
